# 0011. Запросы той же формы, что у Eloquent

**Статус:** Accepted

**Контекст.** Многие запросы оригинала не имеют `ORDER BY` (переменные сервера, аллокации, маунты,
многие списки API). Порядок строк тогда — «естественный» для плана выполнения конкретной СУБД:
например, MariaDB отдаёт `egg_variables` в порядке уникального индекса `(egg_id, env_variable)`, т.е.
по алфавиту, а не по `id`. Порядок виден в ответах (окружение в конфиге Wings, списки API).

**Решение.** Если оригинал не сортирует — не сортируем и мы, и выполняем SQL той же формы (те же
JOIN/WHERE, `select *`/`table.*`), чтобы планировщик выбрал тот же план (`pelican_db::raw::stmt` с
кавычками по грамматике Laravel). Если оригинал сортирует — сортируем так же. Строки с одинаковым
ключом сортировки и прочие недетерминированные случаи фиксируются в спеках/тестах.

**Последствия.** Порядок совпадает с оригиналом на каждой СУБД (подтверждается диф-тестами на 4 СУБД).
Нельзя «улучшать» запросы добавлением сортировки или выборкой подмножества колонок без проверки.
