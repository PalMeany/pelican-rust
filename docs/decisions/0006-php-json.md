# 0006. PHP-совместимый JSON

**Статус:** Accepted (детали уточняются по спекам API)

**Контекст.** Совместимость «байт-в-байт» для Wings и форматы ответов API: PHP `json_encode` по
умолчанию экранирует `/` как `\/` и не-ASCII как `\uXXXX` (суррогатные пары), пустой PHP-массив — `[]`
(даже там, где по смыслу объект), float печатаются с `serialize_precision=-1`; порядок ключей — порядок
вставки.

**Решение.** `laravel-compat::json` — собственный `serde_json::Formatter`, воспроизводящий флаги
`json_encode` (по умолчанию 0; поддержка `JSON_UNESCAPED_SLASHES`, `JSON_UNESCAPED_UNICODE`,
`JSON_PRETTY_PRINT` с 4 пробелами и др. — что реально используется оригиналом), `serde_json` с
`preserve_order`. Ответы строятся из упорядоченных структур/`IndexMap`, пустые «ассоциативные массивы»
явно сериализуются как `[]`, где так делает оригинал.

**Последствия.** Все HTTP-ответы идут через единый `PhpJson` responder; диф-тесты сравнивают тела побайтно
для Remote API и после нормализации динамики для остальных.
