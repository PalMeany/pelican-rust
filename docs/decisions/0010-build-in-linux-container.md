# 0010. Сборка и тесты в Linux-контейнере

**Статус:** Accepted

**Контекст.** На хосте macOS не принята лицензия Xcode → `cc`/линковщик недоступны (QUESTIONS Q2);
Docker тоже только внутри lima VM.

**Решение.** `scripts/cargo` запускает cargo в контейнере `pelican-rs-dev` (rust:1-trixie + клиенты СУБД)
внутри VM `pelican`; репозиторий смонтирован по тому же абсолютному пути (rw), target и registry — в
docker-томах; контейнер подключается к сети диф-тестов, поэтому тесты видят `mariadb`, `mysql`,
`postgres`, `panel-orig` по имени сервиса.

**Последствия.** Все команды сборки/тестов — через `scripts/cargo`. Воркерам разрешён этот скрипт.
