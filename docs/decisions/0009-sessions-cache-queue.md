# 0009. Сессии, кэш и очереди без PHP-форматов

**Статус:** Accepted

**Контекст.** Laravel хранит сессии/джобы в PHP-serialize; совместимость с ними не требуется
(пользователи могут перелогиниться), но схему БД менять нельзя (0003).

**Решение.** Сессии UI — в существующей таблице `sessions` (id, user_id, ip_address, user_agent,
payload, last_activity) с собственным форматом payload (JSON, base64), cookie — своё имя.
Кэш и rate limiting — в памяти процесса (опционально Redis позже). Очередь — внутрипроцессная
(tokio), состояние расписаний — в `schedules`/`tasks` как у оригинала; таблицы `jobs`/`failed_jobs`
не используются.

**Последствия.** Одновременная работа PHP- и Rust-панели на одной БД не поддерживается как режим
(но и не ломает данные). Горизонтальное масштабирование Rust-панели потребует Redis для лимитов.
