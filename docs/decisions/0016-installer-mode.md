# 0016. Веб-инсталлятор: режим без БД и передача слушателя панели

**Статус:** Accepted

**Контекст.** В оригинале `APP_INSTALLED=false` открывает `/installer` (Filament-визард `PanelInstaller`):
7 шагов (требования, окружение, БД, яйца, кеш, очередь, сессии), каждый шаг пишет свою часть `.env`
(`writeToEnv` с `array_filter`), последний запускает миграции, сидер, создаёт админа, ставит
`APP_INSTALLED=true` и логинит его. PHP перечитывает `.env` на каждый запрос, поэтому панель «появляется»
сразу. У нас `boot()` требует рабочую БД, а конфигурация читается один раз.

**Решение.**
- `pelican serve` при `APP_INSTALLED=false` не подключается к БД: генерирует `APP_KEY`, если его нет
  (`key:generate`), и обслуживает отдельный роутер инсталлятора (`pelican_web::installer`) на том же
  слушателе; остальные пути редиректят на `/installer`.
- Визард без серверного состояния: значения пройденных шагов едут скрытыми полями формы (сессий ещё
  нет — драйвер выбирается на последнем шаге). CSRF — double-submit: случайный токен в cookie
  `pelican_installer` и поле `_install_token`.
- Каждый шаг валидируется и пишет `.env` так же, как оригинал (`write_variables`, ADR-0014); шаг БД
  проверяет подключение, шаг Redis — `PING`. Финиш: схема из эталонного дампа (`install_fresh`, ADR-0003),
  роль Root Admin, админ (`create_admin`), установка выбранных яиц в фоне, `APP_INSTALLED=true`.
- Передача: финиш синхронно (до ответа) вызывает колбэк бинаря, который строит панель
  (`start_panel`: `Live`, планировщик, перечитывание) и подменяет роутер за слушателем. Только после
  этого уходит редирект `/installer/complete?token=…` — одноразовый токен логинит админа
  (`auth()->login($user, true)`) и ведёт в `/admin`. Асинхронная подмена давала гонку: браузер успевал
  прийти на `/installer/complete` к роутеру инсталлятора.

**Последствия.** Установка с нуля не требует CLI и рестарта. Повторно открыть инсталлятор после
`APP_INSTALLED=true` нельзя (404), как в оригинале. Ошибки финиша (миграции, создание пользователя,
запись `.env`) показываются баннером на последнем шаге, данные визарда не теряются.
