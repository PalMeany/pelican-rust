# 0015. Журналы в формате Laravel

**Статус:** Accepted

**Контекст.** Страница «Panel Logs» оригинала (filament-log-viewer) читает файлы канала `daily`
(`storage/logs/laravel-YYYY-MM-DD.log`). Rust-панель пишет события через `tracing` в stdout.

**Решение.** Бинарь в режиме `serve` дублирует собственные события (цели `pelican*`) в файлы
по правилам Laravel: `LOG_CHANNEL` (`daily` по умолчанию, `single`, `stack` с первым каналом из
`LOG_STACK`), `LOG_LEVEL` (notice/warning → WARN, critical и выше → ERROR), `LOG_DAILY_DAYS`
(14), формат Monolog `[Y-m-d H:i:s] <APP_ENV>.<LEVEL>: <message> <context JSON>`, время в
`APP_TIMEZONE`. Поля события → контекст. Просмотрщик разбирает файлы как пакет (заголовки по
`[дата время]`, уровень по `.LEVEL:`, контекст — первый сбалансированный JSON, стек — строки до
следующего заголовка), поэтому старые журналы PHP-панели и новые показываются вместе.

**Последствия.** Консольный вывод по-прежнему управляется `RUST_LOG`; файловый слой от него не
зависит. Журналы зависимостей (sqlx, hyper) в файлы не попадают.
