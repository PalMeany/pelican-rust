# 0007. Дифференциальное тестирование

**Статус:** Accepted

**Решение.**
- Оригинал (`pelican-orig:dev`, собран из `../panel/Dockerfile.dev`) и БД (MariaDB 11.4, MySQL 8.4,
  PostgreSQL 17, SQLite-файл в общем каталоге) — `difftest/compose.yml` в lima VM `pelican`.
  Оригинал запускается без cron/очередей, `CACHE_STORE=array`, `SESSION_DRIVER=array`,
  `QUEUE_CONNECTION=sync`: всё состояние — в БД.
- Mock Wings (часть харнесса) записывает входящие запросы панели и отдаёт заготовленные ответы.
- Сценарий (YAML): фикстура (набор строк БД), последовательность HTTP-запросов, ожидания.
  Прогон: восстановить снапшот → запросы к оригиналу → снять ответы, дамп БД, вызовы Wings →
  восстановить снапшот → то же для Rust → нормализовать (время, случайные токены/uuid по
  правилам сценария, JSON-колонки семантически) → сравнить.
- Обе панели используют одну БД последовательно, один `APP_KEY`.

**Последствия.** Фича готова только с зелёным диф-тестом. Нормализация — явная и минимальная,
по полям, перечисленным в сценарии.
