# Вопросы

Формат: вопрос → выбранный по умолчанию вариант (**DEFAULT**) → статус. Отвечайте прямо в файле
или в чате; после ответа вариант помечается ✅ или переделывается.

## Q1. Какие СУБД поддерживать?
В задаче «[какие нужны]». **DEFAULT:** все, что поддерживает оригинал: MySQL 8, MariaDB, PostgreSQL,
SQLite. Тестируем на MariaDB 11.4, MySQL 8.4, PostgreSQL 17, SQLite. — открыт

## Q2. Лицензия Xcode на хосте
`cc`/линковщик на macOS не работает: «You have not agreed to the Xcode license agreements»
(нужен `sudo xcodebuild -license accept`, требует пароль — сам не делаю). **DEFAULT:** собираю и тестирую
в Linux-контейнере внутри lima VM `pelican` (`scripts/cargo`, ADR-0010). Если примете лицензию —
станет возможна и нативная сборка, но сценарий через VM останется основным. — открыт

## Q3. Docker
Docker Desktop не установлен. **DEFAULT:** создана отдельная lima VM `pelican` (6 CPU, 8 GiB, 60 GiB,
шаблон docker, rootless); в её конфиг добавлены rw-маунты `../.difftest` и `./` (pelican-rs).
Существующую VM `flowlock-linux` не трогаю. Удалить: `limactl delete pelican`. — открыт

## Q4. Префикс таблиц `DB_PREFIX`
**DEFAULT:** не поддерживается в MVP (почти не используется); при непустом префиксе — ошибка старта. — открыт

## Q5. «Нулевые» даты MySQL (`0000-00-00 00:00:00`) в старых БД
Оригинал в нестрогом режиме мог их записать; sqlx не декодирует. **DEFAULT:** пока не обрабатываются;
если встретятся — будут читаться как NULL (доработка `Timestamp`). — открыт
